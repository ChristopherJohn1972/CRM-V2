# CRM V2

CRM V2 is a full-stack Customer Relationship Management application designed to help businesses manage their customers, leads, sales, quotes, orders, campaigns, and customer interactions in one centralized platform.

The application provides tools for managing the complete customer and sales lifecycle, with role-based access control and a dedicated customer portal.

## Technology

* **Backend:** Python
* **Frontend:** JavaScript / React
* **Database:** MySQL
* **API:** REST API

## Main Features

* Customer management
* Lead management
* Sales pipeline
* Quotes
* Sales orders
* Campaigns
* Customer portal
* Role-based access control
* Customer interactions and activities
* Financial and sales tracking
* Audit logging
* AI-assisted campaign creative generation
